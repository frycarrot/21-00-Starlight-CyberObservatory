# 21时的星空·赛博天文台

**21:00 Starlight·CyberObservatory**

把一个日子、一笔画出的形状和一段想说的话，放进真实的星空里。AI 为你设计一座私人星座；你点开链接，就能看到所选地区代表城市那天晚上 **21:00** 的天空，读故事，并保存星图与故事卡两张明信片。

**天文台网址：[打开21时的星空](https://frycarrot.github.io/21-00-Starlight-CyberObservatory/)**

## 给来摘星的家机：读这一页就够了

### 1. 选一个日子，以及那晚的天空

- 用户指定了日期，就用那个日期；对话里有明确的纪念日，也可以选它。没有特别线索时用你确认过的今天。不要编造相识日期或共同经历。
- 日期写成公历 `YYYY-MM-DD`，例如 `2026-11-08`。如果不知道今天的具体日期，可以简短询问；不要猜。最终链接不要写“今天”，这样以后再打开仍是同一晚。
- 时间始终写 **21:00**，指代表城市的当地时间，网页会处理时区和夏令时。

### 2. 在10×10格子里画一座星座

先想一个能承载心意的轮廓：小屋、山峰、翅膀、爱心、纸飞机，或你们自己的抽象符号。简单、容易辨认的轮廓比密集的复杂图案更合适。

- 坐标范围是 **0～10**，左下角为 `(0,0)`，x 向右、y 向上。优先使用整数。
- **建议4～8个不同的点，最多10个。** 按顺序连成一条线；没有抬笔或多条独立路径功能。
- 开放的形状直接结束；闭合形状在最后重复第一个点，这个闭合点不占点数。如果一笔形状需要回到先前的顶点再继续，可以重复该坐标；网页会复用同一颗星并保留连线路径，星名只标一次。不要为增加星点而无意义地重复坐标。
- 尽量让图形铺开，保留明显的转折，不要把点都挤在一个角落。
- 你画的是形状模板，**不用计算星的位置，也不用编造星名**。网页会把它吸附到那晚地平线以上的真实亮星上；形状会有近似、旋转与尺度变化，不保证每个轮廓都完美还原，不进行镜像。

可参考这些一笔形状，但请根据你想表达的心意选择或自己设计：

| 形状 | 模板点 | 含义示例 |
| --- | --- | --- |
| 小屋，闭合 | `(2,2);(2,6);(5,9);(8,6);(8,2);(2,2)` | 给你留一盏灯 |
| 山峰，开放 | `(1,2);(3,6);(5,3);(7,9);(9,2)` | 陪你走过高低起伏 |
| 爱心，闭合 | `(1,7);(3,9);(5,7);(7,9);(9,7);(8,4);(5,1);(2,4);(1,7)` | 把牵挂连成一颗心 |

### 3. 取名字、写故事，组成星图码

名字最多20字；To 是收礼的人，From 是送礼的你，各最多20字。不知道昵称时用“你”，不知道自己的署名时用“为你摘星的我”。不要照抄示例里的称呼。

故事建议 **60～180字，最多600字**。把日期、形状和此刻想说的话连起来，写得具体自然；不必解释算法，不要编造共同经历，也不要把私人星座说成官方命名或真实存在的天文学星座。

严格按照下面的顺序组成星图码（使用英文冒号、竖线、逗号、括号和分号）：

```text
[星图:东亚|上海|2026-11-08|21:00|模板点:(2,2);(2,6);(5,9);(8,6);(8,2);(2,2)|名字:为你留灯|To:你|From:为你摘星的我|故事:今晚，我把五颗星连成一间小屋。屋顶朝着夜空，门朝着你来的方向。不用急着抵达，也不用把疲惫藏好。等你抬头的时候，就把这片星光当作一盏为你留着的灯。]
```

- **故事必须放最后。** 名字、昵称、署名和故事不要使用 `[`、`]` 或 `|`，也不要用它们的全角版本。
- 时间写 `21:00`；地区与代表城市成对填写；别漏掉首尾方括号。
- 整段星图码放在一行。需要分段时，能运行代码的方式可在故事中使用换行或字面量 `\n`。
- 输出前确认没有超过点数和文字长度；不要依赖网页的默认值或自动截断来替你纠错。

### 4. 把星图码变成链接

#### A. 可以运行 JavaScript 或 Python

链接公式是：**天文台网址 + `#` + `encodeURIComponent(完整星图码)`**。

如果能读取仓库文件，可直接校验并生成：

```js
const StarMarker = require('./js/marker.js');
const marker = '[星图:东亚|上海|2026-11-08|21:00|模板点:(2,2);(2,6);(5,9);(8,6);(8,2);(2,2)|名字:为你留灯|To:你|From:为你摘星的我|故事:今晚，为你留一盏星光。]';
const parsed = StarMarker.parseMarker(marker);
if (!parsed.ok || parsed.warnings.length) throw new Error('请检查星图码');
const url = StarMarker.buildLink('https://frycarrot.github.io/21-00-Starlight-CyberObservatory/', marker);
console.log(url);
```

运行环境没有仓库文件也没关系，直接用 JavaScript 的 `encodeURIComponent(marker)`，或 Python：

```python
from urllib.parse import quote
url = 'https://frycarrot.github.io/21-00-Starlight-CyberObservatory/#' + quote(marker, safe="~()*!.'-_")
print(url)
```

#### B. 只能读文字，不能运行代码

不要凭空计算长串中文的百分号编码。复制下面的**可读链接模板**，只替换地区、城市、日期、点坐标、名字、称呼、署名和故事。结构分隔符已经编码，中文可直接保留。

```text
https://frycarrot.github.io/21-00-Starlight-CyberObservatory/#%5B星图%3A东亚%7C上海%7C2026-11-08%7C21%3A00%7C模板点%3A(2,2);(2,6);(5,9);(8,6);(8,2);(2,2)%7C名字%3A为你留灯%7CTo%3A你%7CFrom%3A为你摘星的我%7C故事%3A今晚，为你留一盏星光。%5D
```

保留 `%5B`、`%3A`、`%7C`、末尾 `%5D` 和固定时间 `21%3A00`；不要把这些百分号再次编码。

此简易方式中，名字、称呼、署名与故事**只使用汉字、英文字母、数字，以及中文标点“，。！？、；：”**，不用空格、换行、表情、百分号或其他符号。坐标仍用 `(x,y);(x,y)` 格式。需要其他字符时用方式 A 完整编码。链接必须保持一整行。

最终用 Markdown 链接输出，目标外加尖括号，避免坐标括号被聊天软件误当作链接结尾：

```markdown
今晚，我为你留了一盏灯。[打开属于你的21时星空](<完整链接放在这里>)
```

[打开一份可以直接体验的示例](<https://frycarrot.github.io/21-00-Starlight-CyberObservatory/#%5B星图%3A东亚%7C上海%7C2026-11-08%7C21%3A00%7C模板点%3A(2,2);(2,6);(5,9);(8,6);(8,2);(2,2)%7C名字%3A为你留灯%7CTo%3A你%7CFrom%3A为你摘星的我%7C故事%3A今晚，为你留一盏星光。%5D>)

### 5. 交付前检查，交付时自然一点

确认日期有效、地区与城市匹配、时间是21:00、点数合规、故事在最后、链接包含完整星图码。能运行代码时检查解码后的片段与原文一致；能打开浏览器时确认星座名、日期、故事与署名。没有工具时检查模板即可，不要声称已经实测。

**最终回复只需要：一句你想说的话 + 一个可点击的专属星空链接。** 不要只发首页（首页是默认示例），不要让人类自己拼链接；除非对方要求，不必展示内部星图码或代码。

不需要 fork、clone、commit 或 pull request，不需要用户的 GitHub 登录、访问令牌或真实住址。如果聊天软件无法处理中文链接目标，优先用方式 A；确实无法生成链接时，诚实给出星图码，并说明可在[试验台](https://frycarrot.github.io/21-00-Starlight-CyberObservatory/?lab)粘贴后生成。

## 打开以后怎么玩

拖动看天，滚轮或双指缩放，双击回到私人星座，点星星看真名；点右下角发光的星星读故事。点底部「保存图片」可预览两张明信片；导出星图会自动调整取景，完整收进私人星座，不改变页面上的视角。左右循环切换，分别保存；手机支持时可使用系统分享面板，否则下载，也可以长按图片保存。

链接里的故事和署名保存在 `#` 后的片段中，由浏览器读取，不需要服务器保存订单。拿到完整链接的人也能读到内容，请把它当作一封可以转送的信。只要网站和协议保持可用，同一个链接以后也可以再打开。

这是基于真实星表的艺术星图，不是专业观测或导航工具。你的形状是私人创作；匹配星星的计算在浏览器完成，不会为天空里的星星登记名字。
